# เว็บไซต์ติดตามนักศึกษาฝึกงาน — วิทยาลัยเทคนิคเลย

เว็บไซต์นี้ทำเลียนแบบหน้าตาเว็บต้นฉบับที่คุณส่งมา มี 4 หน้า และใส่ข้อมูลจริงของทีมคุณ
(ชื่อ, รหัสนักศึกษา, เบอร์โทร, ที่อยู่วิทยาลัย) ตามที่เห็นในภาพหน้าจอที่ส่งมาแล้ว

## โครงสร้างไฟล์
```
loeitech-intern/
├── index.html     ← หน้าแรก (เกี่ยวกับทีม + สมาชิก)
├── log.html       ← หน้าลงเวลา (ตารางเวลาเข้า-ออก)
├── tasks.html     ← หน้างานที่ได้มอบหมาย (สัปดาห์ฝึกงาน)
├── admin.html     ← ★ หน้ากรอกข้อมูล มีฟอร์มให้กรอก ไม่ต้องแก้โค้ด
├── data.js        ← ไฟล์ข้อมูลเริ่มต้น (ค่าตั้งต้นที่เว็บใช้ถ้ายังไม่เคยกรอกผ่าน admin.html)
├── common.js      ← โค้ดใช้ร่วมกัน (scroll bar, back-to-top, avatar, ระบบโหลดข้อมูลที่กรอกไว้)
├── style.css      ← สไตล์กลางของเว็บ
├── img/           ← ใส่รูปสมาชิก / โลโก้ / รูปวิทยาลัยที่นี่ (ถ้าไม่อยากอัปโหลดผ่านฟอร์ม)
└── gif/           ← ใส่ gif เพิ่มเติมถ้าต้องการ
```

## 🔥 อัปเดต: เชื่อมต่อ Firebase Realtime Database แล้ว

ตอนนี้เว็บนี้เก็บข้อมูลไว้บน **Firebase Realtime Database** (ฐานข้อมูลกลางบนคลาวด์)
แทนการเก็บใน localStorage ของเครื่องเดียวแล้ว ดังนั้น:

- ใครก็ตามที่เข้าเว็บ (ไม่ว่าเครื่องไหน เบราว์เซอร์ไหน) จะเห็นข้อมูลชุดเดียวกันเสมอ
- กรอกข้อมูลผ่านหน้า `admin.html` แล้วกด "บันทึก" ปุ๊บ ทุกคนที่เปิดเว็บจะเห็นการเปลี่ยนแปลงทันที (แค่ต้องรีเฟรชหน้า)
- ไฟล์ `firebase-sync.js` คือไฟล์ที่เชื่อมต่อกับฐานข้อมูล มีตัวแปร `FIREBASE_URL` ชี้ไปที่ฐานข้อมูลของทีมคุณ

ไม่ต้องกดปุ่ม "ส่งออกเป็นโค้ด" หรือแก้ไฟล์ `data.js` เองอีกต่อไปแล้ว (ปุ่มนั้นยังอยู่ไว้เผื่อทำสำรองข้อมูล เท่านั้น)

⚠️ **ข้อควรรู้ด้านความปลอดภัย:** ฐานข้อมูลนี้ตั้งเป็นโหมด "test mode" ซึ่งเปิดให้ใครก็ตามที่รู้ลิงก์
`FIREBASE_URL` แก้ไขข้อมูลได้ เหมาะกับกลุ่มเล็ก ๆ ที่ไว้ใจกัน (เช่น ทีมฝึกงาน) แต่ไม่ควรใช้เก็บข้อมูลสำคัญมาก
ถ้าต้องการความปลอดภัยเพิ่ม ให้ปรึกษาผู้ช่วยเพื่อตั้งกฎ Firebase Rules เพิ่มเติมได้

## ✏️ วิธีกรอกข้อมูล — ใช้หน้า "จัดการข้อมูล" ในเว็บได้เลย

เปิดเว็บ (ผ่าน Live Server) แล้วกดเมนู **⚙️ จัดการข้อมูล** ด้านบน จะมี 3 แท็บ:

1. **ข้อมูลเว็บไซต์** — ชื่อวิทยาลัย, ที่อยู่, เบอร์โทร, ชื่อรุ่นฝึกงาน, วันเริ่ม-สิ้นสุด, เวลาเข้า-ออกงาน, รูปอาคาร
2. **สมาชิก** — เพิ่ม/ลบ/แก้ชื่อ รหัสนักศึกษา เบอร์โทร ตำแหน่ง และอัปโหลดรูปโปรไฟล์ได้เลย
3. **ลงเวลา** — กรอกเวลาเข้า-ออกจริงของแต่ละคนแต่ละวัน (เลือกสมาชิก → เลือกวันที่ → ใส่เวลาเข้า/ออก →
   ใส่หมายเหตุถ้ามี เช่น "ลาป่วย" → กดบันทึก) วันไหนไม่กรอก ระบบจะคำนวณให้อัตโนมัติ
   (เข้า 08:30 ออก 16:30 ทุกวันทำการ เสาร์-อาทิตย์ = วันหยุด) กดบันทึกแล้วระบบจะเลื่อนวันที่ไปวันถัดไป
   ให้อัตโนมัติ กรอกต่อเนื่องได้เร็วขึ้น
4. **งานรายสัปดาห์** — เลือกสัปดาห์ที่ต้องการ แล้วเพิ่มวัน พร้อมอัปโหลดรูปภาพ และพิมพ์รายการงาน
   (พิมพ์บรรทัดละ 1 งาน ในช่อง "งานที่เกี่ยวกับสายงาน" และ "งานที่ไม่เกี่ยวกับสาย")

กรอกเสร็จแต่ละแท็บ **อย่าลืมกดปุ่ม "💾 บันทึก"** ของแท็บนั้น ๆ ข้อมูลจะอัปเดตทันทีในหน้าแรก/ลงเวลา/งานที่มอบหมาย

### ⚠️ ข้อควรรู้สำคัญเกี่ยวกับการกรอกผ่านฟอร์ม
ข้อมูลที่กรอกผ่าน `admin.html` จะถูกเก็บไว้ใน **localStorage ของเบราว์เซอร์เครื่องที่กรอกเท่านั้น**
(ไม่ได้เก็บลงไฟล์ ไม่ได้ขึ้นเซิร์ฟเวอร์) ซึ่งหมายความว่า:
- ถ้าเปิดเว็บจากเบราว์เซอร์อื่น เครื่องอื่น หรือโหมดไม่ระบุตัวตน จะ**ไม่เห็น**ข้อมูลที่กรอกไว้
- ถ้าล้างประวัติเบราว์เซอร์ (clear browsing data) ข้อมูลจะหายไปด้วย
- เหมาะกับการกรอกทดสอบ/ดูตัวอย่างเฉพาะตัวคุณเองก่อน

**ถ้าต้องการให้ทุกคนที่เข้าเว็บ (หลัง deploy ขึ้น Vercel) เห็นข้อมูลเดียวกัน** ให้ทำตามนี้:
1. กรอกข้อมูลให้ครบผ่าน `admin.html` แล้วบันทึกทีละแท็บให้เรียบร้อย
2. กดปุ่ม **"📋 ส่งออกเป็นโค้ด"** ที่ด้านล่างหน้า จะได้กล่องโค้ดขึ้นมา
3. คัดลอกโค้ดทั้งหมด แล้วเปิดไฟล์ `data.js` วางแทนที่ตัวแปร `SITE`, `MEMBERS`, `WEEK_DETAILS` เดิม
4. บันทึกไฟล์ `data.js` แล้ว deploy ขึ้น Vercel ตามปกติ — ทีนี้ทุกคนที่เข้าเว็บจะเห็นข้อมูลเดียวกันแล้ว

ปุ่ม **"🗑 ล้างข้อมูลทั้งหมด"** ใช้ล้างข้อมูลที่กรอกไว้ในเบราว์เซอร์ กลับไปใช้ค่าเริ่มต้นจาก `data.js`

## 🖼️ เกี่ยวกับรูปภาพที่อัปโหลดผ่านฟอร์ม
รูปที่อัปโหลดผ่าน `admin.html` จะถูกแปลงเป็นข้อมูลฝังในตัว (ไม่ใช่ไฟล์แยก) เพื่อความง่าย
แต่ localStorage เก็บได้จำกัด (ประมาณ 5-10MB ต่อเว็บ) ถ้าอัปโหลดรูปเยอะหรือไฟล์ใหญ่เกินไปอาจบันทึกไม่สำเร็จ
— แนะนำใช้รูปที่บีบอัด/ย่อขนาดแล้ว หรือใส่รูปไม่เกิน 2-3 รูปต่อวัน

ถ้าต้องการควบคุมคุณภาพรูปมากกว่านี้ ยังสามารถใส่รูปแบบเดิม (วางไฟล์ใน `img/` แล้วพิมพ์ path ใน `data.js`)
ได้เหมือนเดิมคู่ขนานกันไป

## วิธีทดสอบก่อน deploy
เปิด `index.html` ตรง ๆ ใน browser ได้เลย หรือใช้ VS Code extension "Live Server"
เพื่อให้ลิงก์ระหว่างหน้า (nav) และการบันทึกข้อมูลทำงานถูกต้อง

## วิธี Deploy ขึ้น Vercel (ฟรี)
1. สมัคร/ล็อกอิน https://vercel.com
2. ลากทั้งโฟลเดอร์นี้วางตอนสร้างโปรเจกต์ใหม่ (หรือ push ขึ้น GitHub แล้ว Import Project)
3. กด Deploy จะได้ URL แบบ `your-project.vercel.app` ทันที
4. **อย่าลืม** ทำขั้นตอน "ส่งออกเป็นโค้ด" ด้านบนก่อน deploy ถ้าอยากให้ทุกคนเห็นข้อมูลที่กรอกไว้

## หมายเหตุ
- Tailwind ใช้แบบ CDN เหมือนเว็บต้นฉบับ ไม่ต้องติดตั้งอะไรเพิ่ม
- ไม่มีฐานข้อมูลจริง ข้อมูลเก็บใน `data.js` (ถาวร ทุกคนเห็นเหมือนกัน) หรือ `localStorage` (ชั่วคราว เห็นเฉพาะเครื่องที่กรอก)
- ถ้าต้องการระบบที่บันทึกข้อมูลได้จริงแบบถาวรและทุกคนเห็นเหมือนกันโดยไม่ต้องแก้ไฟล์เอง (เช่น มีฐานข้อมูลจริง)
  จะต้องต่อ backend/database เพิ่มเติม บอกได้ถ้าสนใจให้ช่วยทำ
